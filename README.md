# Rep Board (hosted page)

The public web page for the Arizona Roofers sales leaderboard. It is an empty shell: it holds
NO sales data, it fetches the live leaderboard file (published nightly by
`~/projects/google-automation/rep_board.py`) when someone opens it, so it is always current and
the source contains no names or dollars. Hosted on GitHub Pages.

To change the page, edit index.html and push; GitHub Pages redeploys automatically.
